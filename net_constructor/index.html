Net Constructor

Interactive network construction + controllable rewiring, distance-based weights & colors, and a spring layout. Click a node to add neighbors. Drag nodes to reposition; pause the layout to freeze.

Build

Click a node and enter how many new neighbors to add. “Distance” used for colors/weights is the graph hop distance from the center node (node 0).

Rewire

Full rewire moves whole edges. Partial rewire splits an edge weight into two random pieces and rewires one piece.

Weights

Weight function: w = w0 · (1 - decay)^g

Rendering

Layout

Drag nodes to move them. Shift+drag pans the view. Wheel zooms.

Save / Load

Saves/loads the non-rewired structure (nodes + base edges). Rewiring is applied after load using the current sliders.
